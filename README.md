## 本地查看

该方案为自包含的单文件 HTML，包含页面样式、脚本和图像资源，无需安装前端依赖。

在本目录执行：

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

在浏览器打开 `http://127.0.0.1:8765/`，点击方案文件。
